# Product core

Status: template; the product has not been defined. Complete this with the owner
before implementation.

## User and problem

Who does the product help? What specific problem does it solve?

## Outcome

What observable outcome would demonstrate that the product is useful?

## Language

Which domain terms are used, and what do they mean?

## Priorities and constraints

When priorities conflict, what matters most: speed, accuracy, cost, or another factor?
Which constraints are mandatory? What is outside the current scope?

## Behavioral rules

None yet. For the first feature, add a document containing the rule, examples,
a link to executable scenarios, and the verification command from the
[scenario map](../specs/README.md).

The human owner defines the core; the agent helps clarify it. Do not infer it
automatically from the incidental behavior of the current implementation.
